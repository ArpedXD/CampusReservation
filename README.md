# Campus Room Reservation (Desktop Application)

A PySide6 desktop application where students browse campus rooms, see who has already booked them, and reserve a time slot.

Think of it as the front desk of a study-room wing, except the clipboard is a window on your screen. It exists so students can check availability before booking, instead of walking across campus to find a locked door.

---

## Features

- **Campus directory:** searchable room list with scrollable room cards (image + description per room, loaded from JSON)
- **Floor browser:** pick a floor, then see its rooms as cards
- **Reservation overlay:** a book-a-room form beside an "Already Reserved" board showing who holds each time slot
- **Profile overlay:** credentials header (picture placeholder, username, email, year level, course, student ID) above a scrollable body
- **Dark-green glassmorphism theme** applied across every widget
